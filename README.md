# 📊 30 Days of Power BI Learning

Welcome to my **30 Days of Power BI Learning Journey!**

I completed a structured 30-day learning program to develop practical skills in Microsoft Power BI, data cleaning, data transformation, data modelling, data visualization, and DAX.

This repository documents my learning progress, concepts, practice work, and dashboard development.

## 🎯 Learning Objectives

- Understand Power BI and its components.
- Import and transform data using Power Query.
- Create relationships and build data models.
- Develop interactive reports and dashboards.
- Learn DAX calculations and measures.
- Present business insights through data visualization.

## 📚 Topics Covered

| Day Range | Topics |
|---|---|
| Day 01–05 | Power BI Introduction, Data Import, Data Transformation |
| Day 06–10 | Data Modelling, Relationships, Page Formatting |
| Day 11–15 | Column, Bar, Line, Area, Waterfall and Funnel Charts |
| Day 16–20 | Scatter, Pie, Donut, Treemap, Map, Gauge and KPI |
| Day 21–25 | Cards, Slicers, Tables, Matrix and DAX Basics |
| Day 26–30 | Calculated Columns, Measures, Date DAX, CALCULATE, DATESBETWEEN, MTD/QTD/YTD and Interactive Dashboard |

## 🛠️ Tools & Skills

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning and Transformation
- Data Modelling
- Data Visualization
